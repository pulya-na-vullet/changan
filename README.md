# Changan Hub — Lamore 2023

Инструмент для **вашего** Changan Lamore 2023 с английской ГУ: подключение по ADB
с Windows-ноутбука кабелем USB-A → USB-A, установка приложений **без сертификата
разработчика Changan**, и правая панель быстрого доступа, которая живёт поверх
всех окон.

Это не взлом чужих машин и не обход чужой защиты «в общем виде». Hub работает
только с головным устройством, которое вы сами перевели в ADB через штатное
инженерное меню.

## Что решено

| Проблема | Как Hub это закрывает |
|---|---|
| Нет developer-сертификата Changan | Локальный ключ с серийником `0xddb66eefd98476f3`. Именно его проверяет `CertificateManager` Feiyu/Wutong, заводской ключ не нужен |
| `adb install` на ГУ закрыт | Файл пушится в `/Download`, ставится `pm install -r -t` с паролем `adb36987` |
| Приложения не видны в лаунчере | Сбрасывается кэш `com.iflytek.autofly.launcher` |
| Нужен быстрый доступ поверх всего | QuickBar — правый док на 13.2″ вертикальном экране |
| USB-A в USB-A Windows не видит машину | Пошаговый мастер + перезапуск adb server + подсказки по драйверу |

## Быстрый старт на Windows

1. Python 3.11+ и `adb` (platform-tools) уже должны быть в PATH.
2. Скачайте ZIP по ссылке выше и распакуйте.
3. Запуск: `python app.py` (или двойной клик по `run.bat` — он поставит зависимости и откроет тот же `app.py`).
4. На ГУ: приложение **Phone** → наберите `*#*#888` → вызов → пароль `369875`.
5. Второй пункт слева (**USB**) → кнопка **ADB**.
6. Кабель **data** USB-A ↔ USB-A в штатный разъём под парящей консолью.
7. В Hub нажмите **Подключить**.
8. Раздел **Правая панель** → **Установить и запустить панель**.
9. Свои APK кладите в `apps/` или через **Выбрать APK**.

Командная строка:

```bat
python -m hub connect
python -m hub overlay
python -m hub install path\to\app.apk
python -m hub apps
```

## Правая панель (QuickBar)

Приложение `com.changanhub.quickbar` держит поверх всех Activity узкую колонку
справа:

- тап — запуск;
- удержание — избранное сверху списка;
- **↔** — широкий режим с названиями и поиском;
- **◂** — сворачивается в тонкий край, чтобы не мешать видео;
- автозапуск после перезагрузки ГУ;
- разрешение «поверх окон» Hub выдаёт сам через `appops`.

Экран Lamore 2023 — **13.2″ вертикальный**. Панель специально узкая, чтобы не
съедать карту навигации.

## Подпись без сертификата завода

ГУ отказывается ставить «чужие» пакеты (`xx is not auth, install failed!`).
Проверка смотрит **серийный номер** X.509, а не на то, что ключ принадлежит
Changan. Hub выпускает ваш собственный ключ с нужным serial и подписывает APK
v1 (JAR) + v2, если доступен `apksigner`.

Поставленные так приложения система часто считает «авторизованными»: обычное
удаление с ГУ может быть запрещено. Снимайте через Hub / `pm disable-user`,
либо сброс ГУ до заводских.

**Нельзя:** ставить это на чужую машину, отключать Vecentek целиком, шить
случайные `system` образы. `adb root` Hub пробует только как запасной путь и
не ломает разделы, если remount не удался.

## Если Windows не видит ГУ

- Кабель должен быть распаян на данные. Зарядные USB-A↔USB-A часто имеют 2 жилы.
- В инженерном меню включён именно **ADB**, не MTP.
- Диспетчер устройств: неизвестное Android → драйвер [Google USB](https://developer.android.com/studio/run/win-usb) или Universal ADB Driver.
- `adb kill-server` (кнопка в Hub) и снова подключить кабель.
- Перезагрузка ГУ: громкость **−** на руле 10–20 секунд.
- На части ноутбуков USB-A порт в режиме Type-C-only не умеет host. Возьмите другой порт.

Альтернативные коды на части прошивок (если `*#*#888` молчит):

- `*#20228888#*` — переключение USB
- `*#518300#*` — Android Settings / проводник
- `*#518200#*` — файловый менеджер

Shell-пароль, если adbd спросит вручную: `adb36987`.

## Каталог

В Hub есть список того, что обычно ставят на экспортную английскую ГУ:
файловый менеджер, VLC, Organic Maps, NewPipe, Firefox, плюс слоты под
Яндекс Навигатор / Музыку / Telegram — их APK вы скачиваете сами и бросаете
в `apps/`. Сторонние магазины и проприетарные пакеты мы не зеркалируем.

## Сборка QuickBar.apk с нуля

Нужны Android SDK (`platforms;android-28`, `build-tools;34.0.0`) и JDK:

```bash
export ANDROID_HOME=/path/to/sdk
python -m pip install -r requirements.txt
python scripts/build_apk.py
```

Готовый файл: `apps/QuickBar.apk`.

## Ограничения

- Экспортная английская ГУ Lamore 2023 на Feiyu (MediaTek 8666). Другие
  поколения Changan часто работают тем же методом, но не обещаны.
- Без включённого ADB поставить ничего нельзя — это штатный переключатель,
  не скрытый эксплойт.
- Overlay может убить штатный лаунчер при нехватке RAM; сверните панель, не
  удаляйте системные пакеты.
- Гарантию дилера такие доработки могут затронуть. Делаете на своей машине.
